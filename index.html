About this practice

This is a practice portfolio, built openly with AI-assisted tooling as part of learning front-end and interactive development — motion, WebGL, layout systems, and the debugging that actually makes a site ship. I designed and shaped every project; an AI assistant helped write code, and in several cases filled real gaps (missing shaders, missing stylesheets, missing assets) and caught real bugs before launch — documented honestly below, project by project, rather than glossed over.

It's still growing. New builds get added as they're finished, each with the same standard: it has to actually work, on a phone as well as a desktop, before it's called done.
